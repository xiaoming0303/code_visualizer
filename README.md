# Python 语法可视化编辑器（Pygame 桌面版）

面向浙江信息科技《数据与计算》模块的 Python 基础语法教学工具。
**学生直接在窗口里修改代码，右侧实时看到变量 / 列表 / 循环 / 分支的执行可视化。**

## 核心特点

1. **左边写代码，右边看结果** —— 编辑时实时解析执行，画面立即跟着变
2. **自定义安全解释器** —— 只支持教学语法，不执行任意系统命令（安全白名单）
3. **单步回放** —— 演示模式下空格播放 / ←→ 单步，逐行观察内存变化（可回退）
4. **内置三套示例** —— 变量与列表 / for与while / if分支，一键载入
5. **友好中文报错** —— 未定义变量、缩进错误、死循环保护，都给出教学提示

## 运行环境

```bash
pip install pygame-ce
python main.py
```

> 说明：Python 3.14 下官方 pygame 无预编译包，使用社区版 `pygame-ce`（API 完全兼容，`import pygame` 即可）。

## 支持的语法（教学范围）

| 类别 | 示例 |
|---|---|
| 变量赋值 | `a = 10` / `b = a * 2` / `s = "hi"` |
| 表达式 | 四则运算、比较、逻辑、字符串拼接、`len()` / `range()` |
| 列表 | `lst = [1, 2, 3]` |
| 列表操作 | `append(x)` / `insert(i, x)` / `pop()` / `remove(x)` / `lst[i] = x` |
| 循环 | `for i in lst:` / `for i in range(5):` / `while a < 5:` |
| 分支 | `if` / `elif` / `else`（支持嵌套） |
| 输出 | `print(a, b)` |
| 注释 | `# 注释行`（不执行） |

## 按键说明

| 模式 | 按键 | 功能 |
|---|---|---|
| 编辑模式（默认） | 直接输入 | 编辑代码（支持中文输入法） |
| | Enter | 换行 |
| | Backspace / Delete | 删除字符 |
| | 方向键 | 移动光标 |
| | **主键盘** 1 / 2 / 3 | 载入三套示例代码 |
| | **数字键盘（小键盘）** | 输入数字（主键盘 1/2/3 已被示例快捷键占用） |
| | Tab | 切换到演示模式 |
| 演示模式 | 空格 | 播放 / 暂停 |
| | ← / → | 单步回退 / 单步前进 |
| | ↑ / ↓ | 调速 |
| | R | 重置回第一步 |
| | Tab | 返回编辑模式 |
| 任意模式 | ESC | 退出程序 |

> 说明：主键盘数字 1/2/3 用作"载入示例"快捷键；**输入数字请使用右侧数字键盘（小键盘）**。

## 界面说明

- **左侧 代码编辑器**：行号 + 当前执行行高亮；编辑时实时预览，演示时单步回放
- **右侧 内存可视化**：数值变量蓝色盒、字符串绿色盒、列表方格组（带下标）、最近操作橙色高亮
- **右下 程序输出**：print 的结果
- **描述栏**：当前步骤的中文讲解 / 红色错误提示

## 教学使用建议

1. **变量赋值**：演示 `a = 10` → `b = a` → `a = 20`，破除"b 会跟着 a 变"的误解
2. **列表操作**：让学生预测 `insert(1, 99)` 后元素怎么移位，再看动画验证
3. **for 循环**：观察循环变量 i 逐次变化、输出逐行出现
4. **if 分支**：改 score 值，看走哪个分支、输出什么
5. **课堂任务**：让学生修改示例代码，例如把 `range(1, 6)` 改成 `range(1, 11)`，观察结果变化
